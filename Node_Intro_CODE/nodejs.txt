node.jsとは？
JavaScriptのランタイム。
元々はJavaScriptはブラウザでしか動かなかったが、JavaScriptをブラウザの外で実装できるようにしたもの。
windowオブジェクトが無かったり、　ブラウザ版とnode.jsとで若干違いがある。

REPL(Read Evaluate Print Loop)
nodeと実行したときにnodeのコマンドが実行できるアレ。
読んで評価して出力してループする
Chromeのコンソールと同じ。
書いたコードをすぐに評価して結果を出力したらまたすぐに次のコードを書ける
nodeと実行するとnode.jsのREPLに入れる。

npm(node package manager)
2つの意味がある
1,他の開発者が公開している何万ものパッケージが管理されている場所(正式にはnpmレジストリ)。
2,これらのパッケージをnode.jsのプロジェクトに簡単にインストールし管理するためのコマンドラインツール
