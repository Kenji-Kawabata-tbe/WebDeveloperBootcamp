■React
フロントエンドのライブラリ。
フレームワークだと言う人もいる。軽量なフレームワークっぽい感じ。
公式はライブラリと言っている。
・コンポーネントを使ってユーザーインターフェースを構築するのに役立つライブラリ
    ・コンポーネントはjavascriptのロジックに加えてhtmlやcssといったビューの内容を組み合わせたもの
    ・基本的には自分自身をhtmlとしてレンダリングする方法を知っている関数
・小さなコンポーネントを組み合わせて大規模なアプリケーションまで作れる

■JSX(JavaScriptXml)
・JavaScriptの構文拡張
・HTMLのようなマークアップをJavaScriptの中に直接書くことが出来る
・ただしJSXはそのままでは「正式な」JavaScriptではないためトランスパイル(変換)が必要
・トランスパイルにはbabelが必要
・JSXのルール
  <br/>や<input/>のような自己終了タグは明示的に閉じる必要がある
  コンポーネントは単一のトップレベル要素しか返せない
  return <input type="password" /><input type="password" />
  みたいなことはできない
